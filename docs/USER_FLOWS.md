# Primary user flows

## 1. Search for a government procedure

1. The user opens Masar's home page.
2. The user enters an everyday Arabic description or a service name in search.
3. Masar shows matching curated procedure results.
4. The user scans the service name, short purpose, and responsible authority.
5. The user opens the relevant service detail page.

If no suitable result is available, Masar shows an honest empty state and offers category browsing or a revised search. It does not invent a procedure or answer.

## 2. Browse by category

1. The user opens Categories from the home page or navigation.
2. The user selects a topic category.
3. Masar displays the procedures in that category.
4. The user opens a service detail page.

## 3. Open a service

1. The user arrives from search results or a category listing.
2. Masar shows the service name, plain-language purpose, and responsible authority first.
3. The user scans the task-oriented guidance sections.
4. Masar shows the official source and last verified date with the information.

## 4. Understand requirements

1. On the service detail page, the user opens or scrolls to “What to prepare.”
2. The user reviews required documents and procedure steps that are officially published.
3. If fees, duration, or online availability are officially published, the user can review them in their clearly labeled sections.
4. If a fact is not officially published, Masar communicates that it is unavailable rather than guessing.

## 5. Find the official source

1. The user reaches the source section on a service detail page.
2. The user sees the source title, official link, and last verified date.
3. The user opens the clearly labeled external official source.
4. If an official online service is available, the user can continue through a separate clearly labeled external link.

## 6. Return or backtrack to another service

1. The user decides the current service is not relevant or wants an alternative.
2. The user uses browser back or the visible link back to the previous search or category.
3. Masar returns the user to the relevant results or listing.
4. The user opens another service without restarting their journey.

## Open decision

- The exact search-result ranking and fallback behavior are not yet defined; the MVP must preserve an honest no-result state.
