# MVP scope

## Must have

- A curated, limited catalogue of Egyptian government procedures. The exact initial procedures are an OPEN DECISION.
- Arabic-first, mobile-first, accessible guidance pages for supported procedures.
- Search for supported procedures using a service name or everyday Arabic query.
- Category browsing for the supported catalogue.
- A service detail page with a plain-language purpose, responsible authority, officially published requirements and steps, when available.
- Official source title and link, plus a last verified date, for factual service guidance.
- Fees, expected duration, and online availability only when officially published.
- Clearly labeled links to official sources and official online services, when available.
- An honest empty state when a procedure is not in the supported catalogue.

## Should have

- Alternative Arabic search terms for supported procedures.
- Contextual links back to the previous search or category.
- A concise About Masar page explaining its guidance role and source-based approach.

## Later

- Expand the verified procedure catalogue and category coverage.
- Improve Arabic search matching, including additional synonyms and normalization.
- Define and publish a detailed source-verification methodology.
- Add a secondary language if evidence supports the need.

## Explicitly out of scope

- Completing, submitting, or tracking government transactions within Masar.
- Inventing, estimating, or presenting unpublished requirements, fees, durations, or procedures as fact.
- Authentication, user accounts, saved services, or personal profiles.
- Social features, notifications, payments, real-time updates, maps, chat, or AI-assisted procedure answers.
- Database schemas, API routes, application code, Strapi, and Figma files at this project stage.

## Open decisions

- The initial supported procedure catalogue and category taxonomy.
- Source eligibility criteria, content review workflow, and verification cadence.
- Exact search matching and result-ranking behavior.
- Content administration approach and technology stack.
