# Masar — مسار

Masar is an Arabic-first guidance and navigation platform for Egyptian government procedures. It helps people find a supported procedure, prepare using source-backed information, and continue to the responsible authority's official service.

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Run linting:

```bash
npm run lint
```

The application foundation is Arabic-first: the root document uses `lang="ar"` and `dir="rtl"`. Product features are intentionally not implemented yet.
